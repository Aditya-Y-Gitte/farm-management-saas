# Farm Management SaaS

This project is a multi-tenant SaaS platform for farmers to manage their livestock, dairy, crops, and overall farm operations.

## Architecture

*   **Frontend:** React with TypeScript
*   **Backend:** .NET Core Web API
*   **Database:** PostgreSQL
*   **Database Migrations:** Evolve

## Modules

*   **Dairy and Livestock Management (Sprint 1)**
*   Farm Management
*   Crop Management
*   AI Services

## Deployment

The goal is to use free or low-cost cloud services to make the platform accessible to a wide range of farmers.
